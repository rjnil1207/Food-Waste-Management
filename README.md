\\🥫 Food Waste Management System

This project is a Streamlit-based web application designed to manage and reduce food waste by connecting food providers with receivers (such as NGOs or food banks). The system leverages a MySQL backend and offers CRUD operations, data filtering, SQL insights, and exploratory data analysis (EDA) of food donation activities.

\\ The application helps answer questions like:

Which foods are available for donation?
Who are the top providers and receivers?
Which types of food are claimed most often?
How can food donations be tracked and filtered?
